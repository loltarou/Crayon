# Crayon Engine - Custom UI Plugin for Pengu Loader

## 概要
本プロジェクトは、Pengu Loaderを介してLeague of LegendsクライアントのUIをカスタマイズするためのプラグインです。
同梱されたローカルサーバーと連携することで、クライアント内の各種画像・動画の動的な差し替え、インゲームUIの配置調整、およびパーティメンバー間でのメディア同期機能を提供します。

## 主な機能
* **UIメディアの差し替え**: 全体背景、プロフィール背景、バナー、エンブレム、アイコン、ボーダー等の画像および動画（WebM）の変更。
* **配置調整パネル**: クライアント上でショートカットキー（Alt + T）を入力することで、任意のメディアをアップロードできるパネル。
* **パーティ同期機能**: 共通のパーティーコードを入力することで、メンバー間で設定したカスタムUIを自動的に共有および同期。
* **外部ツール連携**: クライアント内へのSpotifyコントローラー、およびOP.GG検索ボタンの追加。
* **自動起動システム**: タスクスケジューラを活用し、League of Legendsクライアントの起動に合わせてローカルサーバーをバックグラウンドで自動起動。

## 動作環境
* OS: Windows 10 / 11 (64bit)
* 必須ソフトウェア:
  * League of Legends
  * Pengu Loader


## インストールとセットアップ
1. 本フォルダ（`Crayon`）を、Pengu Loaderの `plugins` フォルダ内に配置してください。
2. League of Legendsクライアント（LeagueClient.exe）を起動し、ログインします。
3. crayon.exeを起動します
4. タスクトレイから終了すれば閉じます。



## 使い方
* **設定パネルの開閉**: クライアント画面がアクティブな状態で `Alt + T` を押下します。
* **メディアの適用**: パネル内の対象タブを選択し、「画像/動画をアップロード」からファイルを選択すると即座に反映されます。
* **UIの非表示化**: パネルの「隠しUI設定」タブから、上部メニューの非表示化などが可能です。
